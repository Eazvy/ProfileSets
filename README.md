Save and apply complete Discord profile presets from the Edit Profile window. Profile Sets supports avatars, banners, bios, pronouns, display names, accent and theme colors, custom statuses and emojis, avatar decorations, profile effects, profile frames, nameplates, name styles, and primary guild identity.

## Features

- Keep separate presets for your main profile and each server profile.
- Preview a preset as a full Discord profile before applying it.
- See animated profile effects, avatar decorations, and banners in preset cards, with settings to control previews.
- Choose which profile fields are saved and which appear on cards.
- Search, rename, update, reorder, randomize, and delete presets.
- Import and export preset collections as JSON backups.
- Page through large collections and optionally reuse main presets while editing server profiles.

Profile Sets loads presets into Discord's profile editor, so you can review the pending changes before saving them.
